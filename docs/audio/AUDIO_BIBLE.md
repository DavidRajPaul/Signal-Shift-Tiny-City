# Audio Bible — Signal Shift: Tiny City
**Status:** Production brief; assets not yet created/licensed.

## Identity
Tactile, warm, precise and calm. Sound reinforces cause/effect. Avoid harsh collision sounds, loud repetitive engines, casino-like rewards and music that competes with reasoning.

| Event | Direction | Requirement |
|---|---|---|
| UI press | Soft tactile click | Short, consistent |
| Signal change | Mechanical/electronic tick | Distinct from UI click |
| Vehicle starts | Gentle motor/roll | No loud repetitive loop |
| Safe passage | Short positive cue | Does not mask other cues |
| Conflict | Restrained negative cue | Clear, not startling |
| Objective progress | Light chime | Reinforces progress |
| Star reveal | Three-stage sparkle/chime | Sync to animation |
| Completion | Brief celebratory sting | Skippable |
| Unlock | Warm bright cue | Avoid casino excess |
| Invalid action | Quiet distinct cue | Pair with visual explanation |
| Ambience | Traffic/birds/wind | Optional and quiet |
| Music | Playful low-distraction loop | Seamless, no vocals needed |

## Mixer rules
Separate Master/Music/SFX/Ambience. Music/SFX/haptics independently adjustable and persisted. Test phone speakers, headphones, low volume and mute. Define cooldowns/polyphony; repeated taps cannot stack uncontrollably. Preload critical cues if needed to avoid hitches. Sound is never the only state indicator. Missing optional audio cannot crash. Haptics optional.

## Music brief
Light modern playful motif, restrained percussion, low tension. It supports thought, not urgency. Separate menu/gameplay tracks only if testing proves value; provide clean loops and brief results transition.

## Licensing and QA
Record filename, creator, source, license, proof/date, attribution, edits and intended use. Prefer original/commissioned or commercially licensed audio. Check AI-audio terms before shipping.
- [ ] Correct cue/event, no duplicates or uncontrolled loops.
- [ ] No clipping; settings affect correct buses and persist.
- [ ] Tested on speaker/headphones/mute.
- [ ] Sound not sole state indicator.
- [ ] License recorded; no first-play hitches.
